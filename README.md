# 🏦 Bank Credit Risk & Loan Portfolio Analysis

## 📌 Project Overview

This project analyzes a loan portfolio to assess credit risk, portfolio exposure, and patterns associated with loan defaults.

Using Microsoft Excel, the analysis examines **32,409 loans** and evaluates portfolio-level KPIs and default rates across borrower and loan characteristics.

The project focuses on transforming raw loan data into meaningful financial insights through data cleaning, KPI analysis, segmentation, PivotTables, and dashboard visualization.
